# Fonts

These fonts are embedded in the generated PDFs. They come from the Google
Fonts releases published as `@expo-google-fonts/*` packages and are
regenerated by `scripts/subset-fonts.sh`.

All of them are licensed under the [SIL Open Font License, Version 1.1](https://openfontlicense.org).
The full license text and copyright notices are in [OFL.txt](./OFL.txt).

The subsets keep Latin, Greek and Cyrillic, punctuation and currency
symbols. They are Modified Versions under the OFL; none of them uses a
Reserved Font Name (DM Serif Display's reserved name is "Source"). Families
whose names are reserved are included unmodified, because the OFL does not
allow a modified version to keep a reserved name.
