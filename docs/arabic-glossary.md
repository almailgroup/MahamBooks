# Arabic glossary

The Arabic interface uses Modern Standard Arabic as written by accountants
and banks in Kuwait. Use these terms everywhere so the same thing always has
the same name. Keep sentences short and direct, and address the user
politely without "please" on every line. Buttons use the verbal noun (حفظ,
إلغاء), as Kuwaiti banking apps do, not the imperative (احفظ).

## Style

- Digits: Western (0–9), as on Kuwaiti invoices, bank statements and KNET
  receipts. Numbers are formatted by the app, never written into the text.
- Currency: د.ك (Kuwaiti dinar), فلس (fils). "KWD" stays as is inside codes.
- Dates: the app formats dates; do not write month names into text.
- Brand: AlmailBooks is never translated.
- Placeholders such as `{name}` and `{count}` stay exactly as they are.
- Use the comma "،" and the question mark "؟" in Arabic text.
- Buttons and menu items: short nouns (حفظ، إلغاء، حذف، تعديل، إرسال، طباعة).
- Status badges: short adjectives (مسودة، مرسلة، مدفوعة، متأخرة).
- Feminine agreement for فاتورة (مدفوعة، مرسلة، متأخرة); masculine for عرض سعر
  and إشعار (مرسل، مقبول).
